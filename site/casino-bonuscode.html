Bonuscode im Casino: wo er hingehört und warum er manchmal nicht greift

Zuletzt aktualisiert: September 2026 · Lesezeit ca. 11 Min. · Bet24Now-Redaktion

Ein Bonuscode ist eine kurze Zeichenfolge, die einem Angebot zugeordnet ist. Du trägst sie im Anmeldeformular, im Kassenbereich oder im Aktionsbereich deines Kontos ein, und der Anbieter weiß dann, welche Aktion für dich gelten soll. Wo genau der Code hingehört, legt der Anbieter fest. In der Praxis scheitert die Sache oft an Kleinigkeiten: am Zeitpunkt der Eingabe, an einer abgelaufenen Aktion, an der gewählten Zahlungsart oder daran, dass das Angebot für dein Konto nie vorgesehen war. Danach ist die Einzahlung gebucht, der Bonus fehlt, und der Support verweist auf die Bedingungen.

Worum es hier geht. Es geht um die Mechanik hinter Bonuscodes: Eingabe, Reihenfolge, typische Fehlerquellen und die Bedingungen, die nach der Gutschrift greifen. Konkrete Codes oder Angebote einzelner Anbieter findest du hier nicht, weil sie sich laufend ändern und ein Code ohne die zugehörigen Bedingungen nichts wert ist.

Was ein Bonuscode ist und was er auslöst

Technisch ist ein Bonuscode ein Schlüssel. Er verbindet dein Konto mit einem hinterlegten Angebot, etwa einem Einzahlungsbonus, einer Freispielaktion oder einer Rückvergütung. Ohne diesen Schlüssel läuft die Einzahlung als normale Einzahlung durch, und das Angebot bleibt im System liegen.

Über die Qualität des Angebots sagt der Code nichts. Er ist eine Kennung. Was ein Bonus wert ist, hängt an den Bedingungen dahinter, vor allem am Umsatzfaktor, also daran, wie oft der Betrag eingesetzt werden muss, bevor eine Auszahlung möglich ist. Wie sich daraus der nötige Umsatz ergibt, zeigt unser Guide zum Casino-Bonus, und die einzelnen Bonusformen ordnet unser Beitrag zu Bonusarten im Casino ein.

Code, Aktion und Kampagne

Ein und dieselbe Aktion kann unter mehreren Codes laufen, zum Beispiel einem für den Newsletter und einem für Partnerseiten. Umgekehrt kann ein Code an eine einzelne Person gebunden sein. Personalisierte Angebote tauchen nur im Konto der jeweiligen Person auf. Ein Code, der bei jemand anderem funktioniert hat, muss bei dir also nicht funktionieren.

Wo der Code eingetragen wird

Es gibt drei übliche Stellen. Die erste ist das Registrierungsformular. Dort findet sich häufig ein Feld mit der Bezeichnung „Bonuscode“ oder „Aktionscode“, manchmal hinter einem kleinen Link, der das Feld erst aufklappt. Wird der Code hier verlangt und bleibt das Feld leer, lässt sich die Aktion für dieses Konto in aller Regel nicht mehr nachträglich aktivieren.

Die zweite Stelle ist der Kassenbereich, also das Fenster für die Einzahlung. Dort steht das Feld meist direkt unter dem Betrag. Einige Anbieter zeigen an dieser Stelle zusätzlich eine Liste der verfügbaren Aktionen zur Auswahl an.

Die dritte Stelle ist der Aktionsbereich des Kontos, häufig unter „Angebote“ oder „Promotionen“. Dort aktivierst du eine Aktion vorab, und die nächste Einzahlung löst sie dann aus. Welche Angebote wann laufen, ordnet unser Beitrag zum Aktionskalender im Casino ein.

Die Reihenfolge entscheidet

Der häufigste Grund für einen fehlenden Bonus hat nichts mit dem Code zu tun, sondern mit dem Zeitpunkt. Fast alle Einzahlungsboni verlangen, dass der Code vor oder während der Einzahlung im System liegt. Eine bereits gebuchte Einzahlung nachträglich mit einem Bonus zu versehen, ist bei den meisten Anbietern technisch nicht vorgesehen.

Die Gutschrift in der ersten Zeile gilt, sofern auch die übrigen Bedingungen der Aktion erfüllt sind. Die letzte Zeile ist die unangenehmste: Sobald das eingezahlte Geld im Spiel war, lassen sich Einzahlung und Spielverlauf nicht mehr sauber auseinanderrechnen. Manche Anbieter buchen in solchen Fällen aus Kulanz etwas nach, wie unser Beitrag zur Kulanzgutschrift im Casino beschreibt.

Warum ein Code nicht greift

Wenn das Feld den Code zurückweist oder der Bonus trotz korrekter Eingabe ausbleibt, kommen meist diese Ursachen infrage.

  • Die Aktion ist abgelaufen. Codes tragen fast immer ein Enddatum, und Vergleichsseiten hinken manchmal hinterher.
  • Der Code gilt nur für Neukunden, dein Konto besteht aber bereits.
  • Der Code wurde bereits eingelöst. Viele Anbieter rechnen dabei pro Haushalt oder pro Gerät, nicht pro Person, wie unser Text zum Doppelkonto im Haushalt beschreibt.
  • Die gewählte Zahlungsart ist von der Aktion ausgenommen. Manche Anbieter schließen bestimmte Methoden vom Bonus aus.
  • Der eingezahlte Betrag liegt unter dem Mindestbetrag der Aktion.
  • Eine Dokumentenprüfung läuft noch. Bei deutschen Anbietern wird deine Identität ohnehin vor dem ersten Spiel geprüft, offene Rückfragen können eine Gutschrift aber verzögern.
  • Im Konto ist eine Einstellung aktiv, die Bonusangebote ausschließt.
  • Das Angebot stammt aus einer anderen Länderversion der Seite und gilt in der Regel nicht für Konten im deutschen Markt.

Bei manchen Anbietern ist die Werbeeinwilligung technisch mit der Bonusvergabe verknüpft. Wer Werbung und Angebote abbestellt hat, bekommt dort auch keine Boni mehr gutgeschrieben. Ob das auf dein Konto zutrifft, zeigt ein Blick in die Kontoeinstellungen, wie unser Beitrag zum Abbestellen von Casino-Werbung beschreibt.

Nicht mit einem zweiten Konto nachlegen. Wenn ein Code abgelehnt wird, hilft es nicht, es mit einer anderen Adresse oder den Daten eines Angehörigen zu versuchen. Mehrfachkonten führen regelmäßig zur Sperrung und zur Streichung von Bonus und Bonusgewinnen. Ob ein Anbieter darüber hinaus eingezahltes Guthaben einbehalten darf, ist rechtlich umstritten, und darauf sollte sich niemand verlassen. Was Anbieter unter Missbrauch verstehen, steht in unserem Beitrag zum Bonusmissbrauch.

Der Code ist eingelöst: was jetzt gilt

Mit der Gutschrift beginnt der schwierige Teil, das Freispielen. Bonusgeld ist gebundenes Geld, und vier Größen entscheiden darüber, ob daraus auszahlbares Guthaben wird.

Der Umsatzfaktor legt fest, wie oft der maßgebliche Betrag eingesetzt werden muss. Die Frist bestimmt, in welchem Zeitraum das geschehen muss, und die Spielgewichtung regelt, welcher Anteil deines Einsatzes je Spielart angerechnet wird. Dazu kommt häufig eine Obergrenze, die deckelt, wie viel aus dem Bonus überhaupt ausgezahlt werden kann.

Unser Ratgeber zu Umsatzbedingungen erklärt diese Mechanik ausführlich, und der Umsatzbedingungen-Rechner rechnet den nötigen Einsatz für dich aus. Wie unterschiedlich Spielarten angerechnet werden, behandelt unser Beitrag zur Spielgewichtung beim Bonus, und warum Fristen so oft zum Problem werden, zeigt der Text zu Bonusfristen.

Der Betrag, auf den sich der Umsatz bezieht

Ein Umsatzfaktor allein sagt wenig. Er kann sich auf den Bonusbetrag beziehen, auf die Einzahlung oder auf beides zusammen. Aus demselben Faktor werden so sehr unterschiedliche Summen. Wer zwei Angebote vergleichen will, muss beide Angaben nebeneinanderlegen: den Faktor und die Bezugsgröße. Fehlt die Bezugsgröße in der Bewerbung, findet sie sich meist erst in den vollständigen Bonusbedingungen.

Getrennt oder vermischt

Liegen Bonusgeld und Echtgeld in einem Topf und ist der Bonusbetrag selbst nicht auszahlbar, spricht man von einem Sticky Bonus. Werden beide getrennt geführt, heißt das Non-Sticky. Für Auszahlungen während der laufenden Umsatzphase macht das einen spürbaren Unterschied, den unser Beitrag zu Sticky und Non-Sticky Bonus vergleicht.

Was eine Aktion für dich unbrauchbar macht

Manche Angebote passen nicht zur eigenen Spielweise, auch wenn sie großzügig wirken. Ein hoher Bonus mit kurzer Frist verlangt eine Spielintensität, die viele gar nicht wollen. Eine strenge Spielgewichtung schließt die Spiele aus, die du ohnehin bevorzugst. Und eine niedrige Obergrenze macht aus einem großen Betrag ein kleines Ergebnis.

Wie viel Umsatz in einer Frist überhaupt erreichbar ist, lässt sich beim virtuellen Automatenspiel sogar ausrechnen: In Deutschland gilt dort eine Einsatzgrenze von einem Euro je Spiel bei mindestens fünf Sekunden Spieldauer. Mehr als das geht pro Stunde nicht.

Woher Codes kommen, auch von uns

Bonuscodes werden über den Newsletter des Anbieters verteilt, über das eigene Konto, über Partnerseiten und über Vergleichsportale. Der letzte Weg betrifft auch diese Seite, und dazu gehört Offenheit: Vergleichsportale werden für vermittelte Anmeldungen vergütet, oft abhängig von Einzahlungen oder Spielumsätzen der vermittelten Nutzer. Ein Code ist in den meisten Fällen die Kennung dieser Vermittlung. Ein Interesse an Anmeldungen ist damit vorhanden, und deshalb gehört zu jedem Code die Bedingungsseite dazu. Wie das bei uns geregelt ist, steht in unserem Hinweis zu Affiliate-Links.

Wenn eine Seite einen Code groß herausstellt, die Umsatzbedingungen aber ins Kleingedruckte schiebt, erfährst du mehr über die Seite als über das Angebot. Beurteilen lässt sich ein Angebot erst, wenn Umsatzfaktor, Bezugsgröße, Frist, Gewichtung und Höchstgewinn danebenstehen.

Gefälschte Codes und Lockangebote

Im Umfeld von Bonuscodes gibt es Seiten, die mit erfundenen Codes Besucher anlocken. Die Codes funktionieren nicht, die Seite verdient trotzdem an der Weiterleitung. Erkennbar ist das an mehreren Merkmalen: Es fehlen die Angabe des Anbieters, die Bedingungen und ein Datum, dafür gibt es große Versprechen und einen Countdown.

Ernster wird es, wenn Codes für Anbieter ohne deutsche Erlaubnis beworben werden. Solche Anbieter halten sich weder an das anbieterübergreifende Einzahlungslimit von 1.000 Euro im Monat, noch sind sie an die Sperrdatei OASIS angebunden. Für die Untersagung unerlaubter Angebote ist die Gemeinsame Glücksspielbehörde der Länder zuständig, eine Aufsicht, die dir im Streit um eine Auszahlung hilft, hast du dort aber nicht. Was daran hängt, beschreibt unser Beitrag zum Schwarzmarkt im Online-Glücksspiel.

Der Bonus ändert nichts am Einzahlungslimit. Im deutschen Markt gilt ein anbieterübergreifendes Einzahlungslimit von 1.000 Euro im Monat. Es hängt an deiner Person und gilt für alle legalen Anbieter zusammen. Eine Aktion, die eine höhere Einzahlung voraussetzt, lässt sich damit im laufenden Monat schlicht nicht erfüllen. Wer ein eigenes, niedrigeres Limit gesetzt hat, sollte das vor der Rechnung mitdenken, statt es für einen Bonus anzuheben.

Checkliste vor dem Einlösen

Ein kurzer Blick vor der Einzahlung erspart Ärger danach.

  • Steht neben dem Code ein Datum, und ist die Aktion noch gültig?
  • Gilt das Angebot für Neukunden, für Bestandskunden oder für beide?
  • Wie hoch ist der Mindestbetrag der Einzahlung für diese Aktion?
  • Ist deine geplante Zahlungsart vom Bonus ausgeschlossen?
  • Wie hoch ist der Umsatzfaktor, und auf welchen Betrag bezieht er sich?
  • Wie lange läuft die Frist, und passt sie zu deiner tatsächlichen Spielzeit?
  • Gibt es eine Obergrenze für Gewinne aus dem Bonusguthaben?
  • Wo wird der Code verlangt: im Formular, im Kassenbereich oder im Aktionsbereich?

Die Frist verdient besondere Aufmerksamkeit. Ein hoher Bonus mit kurzer Laufzeit erzeugt Druck, in wenigen Tagen viel zu spielen, und dieser Druck ist der eigentliche Preis des Angebots. Mehr zu den üblichen Formulierungen steht in unserem Beitrag zu Klauseln in Casino-AGB.

Wenn kein Code nötig ist

Viele Aktionen laufen ohne Code. Der Bonus wird dann automatisch gutgeschrieben, sobald die Bedingungen erfüllt sind, oder er erscheint als Auswahl im Kassenfenster. Das ist bequemer und weniger fehleranfällig. Typisch ist das bei gestuften Willkommenspaketen und bei Freispielangeboten, die unser Ratgeber zu Freispielen behandelt.

Fehlt ein Codefeld, ist das also kein Fehler. Prüfe in dem Fall im Aktionsbereich, ob die gewünschte Aktion aktiviert werden muss. Angebote ohne vorherige Einzahlung sind dagegen häufiger an einen Code gebunden, weil der Anbieter sie sonst nicht zuordnen kann.

Freispiele laufen nach eigenen Regeln

Bei Freispielaktionen kommt eine zweite Ebene dazu. Neben dem Umsatz für das Bonusgeld gibt es oft eine eigene Anforderung für die Gewinne aus den Freispielen, manchmal auch eine Obergrenze für den Betrag, der daraus ins Echtgeld wandert. Ebenso ist häufig festgelegt, an welchen Spielen die Freispiele eingelöst werden können und welcher Einsatz je Runde dabei zählt. Beides steht in den Bedingungen der Aktion und entscheidet darüber, was am Ende übrig bleibt.

Code vergessen: was der Support tun kann

Wenn der Code nicht eingetragen wurde, entscheidet der Zeitpunkt der Meldung. Sofort nach der Einzahlung und vor der ersten Spielrunde stehen die Chancen auf eine Korrektur am besten. Je mehr Runden dazwischenliegen, desto unwahrscheinlicher wird eine Korrektur.

Für die Anfrage gilt: den Vorgang sachlich schildern, Uhrzeit und Betrag der Einzahlung nennen, den Code angeben und um Prüfung bitten. Screenshots helfen. Wie du eine Anfrage aufsetzt, die bearbeitet statt abgewimmelt wird, zeigt unser Ratgeber zu Support und Beschwerde. Führt das zu keinem Ergebnis, beschreibt unser Beitrag zum Streit um den Bonus die weiteren Wege.

Das Argument für ein Konto ohne Bonus

Ein Bonus bindet Guthaben an Bedingungen. Wenn du ohne Bonus spielst, gilt kein Umsatzfaktor und keine Frist, und du kannst über dein Guthaben verfügen, sobald Verifizierung und die üblichen Auszahlungsprüfungen erledigt sind. Dafür bekommst du auch kein zusätzliches Guthaben. Die Abwägung fällt je nach Spielweise unterschiedlich aus, und sie lohnt sich, statt den Bonus automatisch mitzunehmen.

  • Du willst kleine Beträge einzahlen und flexibel auszahlen können.
  • Du spielst unregelmäßig und würdest jede Frist reißen.
  • Du willst vermeiden, wegen einer Umsatzanforderung länger zu spielen als geplant.
  • Du hast im letzten Bonus die Bedingungen erst nach dem Einzahlen gelesen.

Am schwersten wiegt der dritte Punkt. Eine offene Umsatzanforderung wirkt wie eine Verpflichtung, und dieses Gefühl ist im Spielerschutz ein bekanntes Problem. Die Bundeszentrale für gesundheitliche Aufklärung bezeichnet den Verlust der Kontrolle über Zeit und Geldeinsatz als Warnzeichen für problematisches Glücksspiel. Wer bemerkt, wegen eines Bonus weiterzuspielen, findet in unserem Ratgeber zum verantwortungsvollen Spielen die passenden Werkzeuge. Die Argumente für ein bonusfreies Konto sammelt unser Beitrag zum Spielen ohne Bonus.

Das Wichtigste in Kürze

  • Ein Bonuscode ist eine Kennung für ein hinterlegtes Angebot und sagt nichts über dessen Qualität aus.
  • Der Code gehört in das Registrierungsformular, in den Kassenbereich oder in den Aktionsbereich, je nach Anbieter.
  • Der richtige Code allein genügt nicht: Ohne die richtige Reihenfolge bleibt der Bonus aus.
  • Häufige Ablehnungsgründe sind abgelaufene Aktionen, ausgeschlossene Zahlungsarten, zu kleine Beträge und die Beschränkung auf Neukunden.
  • Nach der Gutschrift zählen Umsatzfaktor, Bezugsgröße, Frist, Spielgewichtung und die Obergrenze für Gewinne.
  • Codes von Vergleichsportalen sind Vermittlungskennungen, für die diese Portale vergütet werden.
  • Kein Codefeld bedeutet oft, dass die Aktion automatisch läuft oder vorab aktiviert werden muss.

Häufige Fragen

Wo trage ich einen Bonuscode im Casino ein?

Je nach Anbieter im Registrierungsformular, im Kassenbereich bei der Einzahlung oder im Aktionsbereich des Kontos. Welche Stelle gilt, steht in den Bedingungen der jeweiligen Aktion. Bei Neukundenangeboten ist es häufig das Anmeldeformular.

Kann ich einen Bonuscode nachträglich einlösen?

Meistens nicht. Die Systeme verknüpfen den Bonus mit der Einzahlung selbst. Wer sofort nach der Buchung und vor der ersten Spielrunde den Support kontaktiert, hat die besten Chancen auf eine Korrektur aus Kulanz. Einen Anspruch darauf gibt es nicht.

Warum wird mein Bonuscode als ungültig angezeigt?

Typische Gründe sind eine abgelaufene Aktion, eine Bindung an Neukunden, eine bereits erfolgte Nutzung, ein zu kleiner Einzahlungsbetrag oder eine vom Bonus ausgeschlossene Zahlungsart. Auch Angebote aus anderen Länderversionen einer Seite gelten in der Regel nicht für Konten im deutschen Markt.

Sind Bonuscodes von Vergleichsseiten anders als die des Anbieters?

Meist steckt dieselbe Aktion dahinter, nur mit einer anderen Kennung für die Vermittlung. Gelegentlich handelt eine Seite eigene Konditionen aus. Maßgeblich bleiben die Bedingungen, die der Anbieter zu diesem Code anzeigt.

Muss ich für einen Bonus einen Code haben?

Nein. Viele Aktionen laufen ohne Code und werden automatisch gutgeschrieben oder im Kassenfenster zur Auswahl angeboten. Fehlt ein Codefeld, lohnt ein Blick in den Aktionsbereich des Kontos.

Was passiert mit dem Bonus, wenn ich die Frist verpasse?

Dann entfallen in aller Regel das Bonusguthaben und die daraus entstandenen Gewinne. Bei vermischtem Guthaben kommt es darauf an, wie der Anbieter den verbliebenen Betrag aufteilt. Das regeln die Bonusbedingungen.

Fazit

Bonuscodes sind eine Verwaltungsfrage. Wer weiß, an welcher Stelle der Code verlangt wird und dass die Reihenfolge zählt, hat die meisten Fehlerquellen ausgeräumt. Der Rest steckt in den Bedingungen, und die liest du am besten, bevor Geld fließt.

Unbequemer ist der zweite Teil der Antwort. Ein Bonus bindet Guthaben, setzt eine Frist und schafft einen Anreiz weiterzuspielen, den es ohne ihn nicht gäbe. Für manche Spielweisen ist das ein fairer Tausch, für andere nicht.

Deshalb lohnt sich die nüchterne Frage vor jedem Code: Würdest du diese Einzahlung auch ohne das Angebot machen, und würdest du danach genauso lange spielen? Wenn die zweite Antwort „nein“ lautet, ist der Bonus teurer, als er aussieht.
